Panduan Koneksi Webhook WhatsApp

Cara menyambungkan endpoint server ini ke WhatsApp Gateway.

URL Endpoint Webhook
http://localhost:3000/api/webhook/whatsapp

💡 Gunakan ngrok atau cloud hosting (Railway/Render) agar URL ini dapat diakses publik oleh gateway WhatsApp: ngrok http 3000

Opsi 1: Fonnte (Sangat Direkomendasikan)

1. Daftar di fonnte.com dan tautkan nomor WhatsApp.
2. Di menu Webhook, masukkan URL webhook publikmu.
3. Masukkan token Fonnte ke berkas .env: FONNTE_TOKEN=... untuk auto-reply via WhatsApp.

Opsi 2: Wablas

1. Masuk ke dashboard Wablas.
2. Atur Webhook URL ke endpoint di atas.
3. Sistem otomatis merespon pesan WhatsApp yang masuk.

Opsi 3: WhatsApp Cloud API (Meta)

Endpoint ini sudah mendukung verifikasi Webhook GET dengan verify token chika_finance_secret.
